# 룩 템플릿 (빈 양식)

이 저장소에는 **기본 룩이 없다.** 색 · 글꼴 · 부품 · 움직임은 선생님이 고른 **레퍼런스(영상 · 이미지)에서 만든다.**
여기 있는 파일은 값이 비어 있는 양식이다. 그대로 쓰지 말고, 레퍼런스를 분석해 채운 결과를 `docs/`와 `src/parts/`에 만든다.

| 양식 | 채워서 만드는 것 |
|---|---|
| `design.md` | `docs/design.md` — 색 · 글자 · 크기 · 질감 · 사진 규칙 |
| `roles.md` | `src/parts/` — 역할 칸마다 부품 html 하나 |

신문 다큐멘터리 룩 예시는 `look-newspaper` 브랜치에 따로 있다. 참고만 하고, 레퍼런스가 있으면 레퍼런스를 따른다.

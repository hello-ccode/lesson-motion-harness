# 부품 역할 칸

룩이 바뀌어도 장면표가 그대로 돌아가도록, 부품은 **역할**로 나눈다. 칸 이름은 고정, 모양은 레퍼런스에서 정한다.
부품 하나 = `src/parts/<이름>.html` 하나. 맨 위 주석에 **바꾸는 부분 · 건드리지 않는 것 · 따로 움직일 수 있는 조각**을 적는다.

| 역할 칸 | 화면에서 하는 일 | 꼭 있어야 하는 것 |
|---|---|---|
| 바탕 | 모든 장면의 맨 아래 층 | 영상보다 크게 (카메라가 움직여도 가장자리 안 보임) |
| 연도 · 시대 | 큰 숫자 + 부제 한 줄 | 숫자 한 자리씩 따로 움직일 수 있게 |
| 제목 + 강조 문장 | 장면 제목 + 교과서 한 문장 | 강조 표시 한 군데 |
| 자료 + 이름 | 사진 · 표 · 그림 한 장 + 이름 · 설명 | 출처 자리 |
| 정의 · 사료 · 정리 | 용어 · 인용 · 마무리 문장 | 출처 자리 · 강조 표시 한 군데 |
| 판정 · 강조 | 짧은 말 한 개 (2~6글자) | — |
| 과목 · 단원 | 영상 내내 같은 자리 라벨 | — |

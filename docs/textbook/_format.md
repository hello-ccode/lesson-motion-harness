# 교과서 .md 형식 규칙

교과서 PDF를 단원별 .md로 옮길 때 이 형식을 지킨다. content-editor와 critic이 이 형식을 읽는다.

1. **파일 하나 = 소단원 하나.** 파일명: `<단원번호>-<소단원이름>.md` (예: `2-1-주기율표.md`)
2. **맨 위 머리말**
   ```
   # 2-1 주기율표
   과목: 통합과학 1 · 대단원: 물질의 규칙성 · 쪽: 84~89
   ```
3. **쪽 번호:** 문단 앞에 `[p.84]`. 한 문단이 두 쪽에 걸치면 시작 쪽.
4. **본문은 요약하지 않고 원문 그대로.** 맞춤법 · 띄어쓰기도 원문대로.
5. **그림:** `[그림 2-3 | p.85 | 무엇을 보여주는 그림인지 한 줄]` — 그림 파일은 넣지 않는다.
6. **표:** md 표로. 표 위에 `[표 2-1 | p.86 | 표 제목]`.
7. **화학식 · 수식:** 아래첨자 `H₂O` 또는 `H<sub>2</sub>O`, 위첨자 `Na⁺`. 교과서 표기 그대로.
8. **강조:** 교과서에서 굵게 된 용어는 `**용어**`.
9. **못 읽은 쪽:** 비워 두지 말고 `[확인 필요 | p.87]`을 남기고 `index.md`에도 적는다.

# 교과서 목차

교과서 PDF를 `_format.md` 형식으로 바꾸면 소단원마다 한 줄씩 채운다.

| 단원 | 파일 | 쪽 | 상태 |
|---|---|---|---|
| 예시 · 주기율표의 역사 | `sample-unit.md` | 예시 1~3 | 직접 쓴 실습용 원고 (교과서 원문 아님) |
| 2-1 복리 | `2-1-복리.md` | 슬라이드 14~19 | 방과후 2차시 머니스피너 수업자료에서 옮김 (교과서 원문 아님) · [확인 필요] 슬라이드16 이율 (선생님 확인: 연 7% · 매달 복리 = 연 7% ÷ 12를 매달) |

> 교과서 원문은 공개 저장소에 올리지 않는다 (`.gitignore`). 이 목차에는 단원 이름 · 파일 · 쪽만 적는다.

# sound.md · 소리 기준 (내레이션 · 효과음 · 볼륨)

> 1주차(금융범죄 예방 영상 두 편)에서 해 보고 정한 소리 규칙을 옮겼다. 원본: 1주차 프로젝트 `docs/motion.md` 0절(0-4 · 0-5)과 4절, 1주차 피드백 보고서. 값마다 출처를 적었다.
> 출처 적는 법: **"1주차 motion.md 4절"** = 1주차 원본 문서, **"1주차 파일을 잼"** = 1주차에 만든 파일을 이번에 직접 재서 얻은 값, **"정한 값"** = 근거가 없어서 정한 값(선생님이 듣고 바꾼다).
> 소리는 **선생님이 직접 듣고** 판단한다. 에이전트는 소리가 좋은지 판정하지 않는다.

## 1. 내레이션
| 무엇 | 값 | 출처 |
|---|---|---|
| 목소리 | Supertonic 3 **F1** (내 컴퓨터에서 만든다, 인터넷 불필요) | 1주차 motion.md 4절 |
| 빠르기 | **1.05** | 1주차 motion.md 4절 |
| 품질 단계 | 8 | 1주차 제작 스크립트(`make_voice.py`)의 설정 |
| 언어 | `ko` | 1주차 제작 스크립트 |
| 장면 길이 | **내레이션에 맞춘다.** 내레이션이 길면 말 속도를 바꾸지 말고 장면을 늘린다 | 1주차 motion.md 4절 |
| 배경음악 | 넣지 않는다(내레이션이 잘 들리게) | 1주차 motion.md 4절 |

- 만드는 법: `scripts/make-voice.py` (문장마다 wav 하나 + `durations.json`). 모델 위치는 `CLAUDE.local.md`에만 적는다(공개 저장소에 올리지 않는 파일).
- **한 곳 설명에 한 문장.** 설명할 곳(표 한 칸, 숫자 하나)마다 문장 하나를 **파일 하나로** 나눈다. 문장 사이는 **1.0초** 띄운다(표시 0.4초 + 이동 0.7초가 들어갈 자리). — 1주차 motion.md 0-3
- **표시는 문장 끝에.** 빨간 동그라미 같은 짚는 표시는 그 곳을 설명하는 문장이 **끝나는 순간(0.5초 안)** 나온다. — 1주차 motion.md 0-3
- 새 정보를 말하는 문장에는 화면에도 같은 낱말이 있다(말과 화면이 같이). — 1주차 motion.md 0-4 · 1주차 피드백 `nt-conc`
- 문장이 시작하고 끝나는 **시각은 음량(`silencedetect`)으로 잰 값**을 쓴다. 받아쓰기(음성 인식) 낱말 시각은 실제보다 1초쯤 이르게 나온 적이 있다. — 1주차 motion.md 0-5(11/8 확인)

## 2. 읽기 표 (대본은 소리 나는 대로)
**대본에는 소리 나는 대로 적고, 화면 글자는 숫자 그대로 둔다.** 대본을 만들 때 이 표를 먼저 적용한다. 새로 틀리게 읽는 곳이 나오면 이 표에 더한다.

| 화면 글자 | 대본에 적는 말 | 출처 |
|---|---|---|
| 112 | 일일이 | 1주차 motion.md 0-5(1편 피드백 1번: "백일이"로 읽음) |
| 1332 | 일삼삼이 | 1주차 motion.md 0-5(예시) |
| 3초 | 삼 초 | 1주차 motion.md 0-5(2편) |
| 5년 | 오 년 | 1주차 motion.md 0-5(2편) |
| 3천만 원 | 삼천만 원 | 1주차 motion.md 0-5(2편) |
| 10만 원 | 십만 원 | 1주차 motion.md 0-5(예시) |
| SNS | 에스엔에스 | 1주차 motion.md 0-5(2편) |

복리 영상에서 먼저 나올 읽기. **아직 소리로 확인하지 않은 예시**이고, 첫 내레이션을 만든 뒤 받아쓰기로 확인해 맞으면 위 표로 옮긴다(정한 값).

| 화면 글자 | 대본에 적는 말 |
|---|---|
| 연 7% | 연 칠 퍼센트 |
| 1년에 10%씩 | 일 년에 십 퍼센트씩 |
| 121만 원 | 백이십일만 원 |
| 133만 1천 원 | 백삼십삼만 천 원 |
| 1만 원 | 만 원 |
| 72 ÷ 6 = 12년 | 칠십이 나누기 육은 십이 년 |

- 내레이션을 만든 뒤 **받아쓰기로 대본과 비교**해 숫자 · 낱말 읽기가 다른 곳을 보고한다(1주차는 whisper large-v3-turbo로 받아쓰기를 했다 — 1주차 피드백 보고서). 단, 받아쓰기는 숫자를 숫자로 적어서 **"백일이"로 읽었는지는 가릴 수 없다.** 그 부분은 선생님이 듣는다. — 1주차 피드백 보고서

## 3. 효과음
| 소리 | 쓰는 곳 | 길이 | 합성 규격 | 출처 |
|---|---|---|---|---|
| `pop` | 새 쪽지 · 카드가 붙을 때 | 0.12초 | 사인파 880Hz, 처음부터 줄어듦, 최대 크기 0.075 | 1주차 파일을 잼 · 쓰는 곳은 1주차 "문자 도착"에서 바꿈(정한 값) |
| `tick` | 생각할 시간 카운트다운 숫자마다 | 0.07초 | 사인파 1600Hz, 빨리 줄어듦, 최대 크기 0.10 | 1주차 파일을 잼 · 1주차 motion.md 4절 |
| `marker` | 빨간 동그라미를 그릴 때 | 0.35초 | 핑크 노이즈를 1.6~2.5kHz 띠로 걸러 끝만 줄임, 최대 크기 0.065 | 1주차 파일을 잼 · 1주차 motion.md 4절 |
| `chime` | 마지막 화면 | 1.2초 | 사인파 1047Hz + 1568Hz, 천천히 줄어듦, 최대 크기 0.087 | 1주차 파일을 잼 · 1주차 motion.md 4절 |

- **네 가지만** 쓴다. 더 필요하면 만들기 전에 선생님께 묻는다. — 1주차 motion.md 4절
- **FFmpeg로 직접 합성한다**(사인파 · 핑크 노이즈). 만드는 법: `scripts/make-sfx.sh` → `src/assets/sfx/*.wav`. 외부 음원은 쓰지 않는다. 쓰게 되면 Openverse **CC0**만 쓰고 `credits.txt`에 적는다. — 1주차 motion.md 4절
- 위 규격은 1주차에 만든 wav 네 개의 길이 · 주파수 · 크기를 이번에 재서 같은 소리가 나게 맞춘 것이다(1주차에는 합성 명령이 글로 남아 있지 않았다).

## 4. 볼륨
- 렌더가 끝난 뒤 FFmpeg `loudnorm=I=-16:TP=-1.5:LRA=11`로 맞춘다(교실 스피커 기준). — 1주차 motion.md 4절
- 맞춘 뒤 `scripts/check-render.sh`가 통합 음량(I)과 최대 피크(TP)를 다시 잰다. 판정 기준은 `docs/check.md`.

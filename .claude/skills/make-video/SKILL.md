# make-video · 수업 영상 한 편 만들기

영상 한 편 = `out/<영상이름>/` 폴더 하나. 이 폴더에는 교과서 원문이 들어가서 **공개 저장소에 올리지 않는다**(`.gitignore`).
시작 전에 `CLAUDE.md` 를 읽는다. **✋ = 선생님 승인을 받기 전에는 다음 단계로 가지 않는다.** 승인은 그 자리에서 선생님이 "좋아요 / 고쳐 줘"로 답한 것만 인정한다.

## 지킬 것 (모든 단계)
- **문서에 없는 값은 지어내지 않고 묻는다.** 질문은 한 번에 묶어서 "무엇이 · 왜 필요한지 · 기본값 후보 한 줄"로 한다.
- 값은 `docs/` 와 `src/parts/` 에서만 가져온다. 룩과 움직임은 `docs/` · `references/` 에서만 가져온다.
- 단계마다 산출물 파일을 `out/<영상이름>/` 에 남긴다(아래). 다음 단계는 앞 파일만 보고 일한다.
- 내 컴퓨터 경로 · 개인 정보 · 학생 이름을 `out/` 밖이나 공개 문서에 적지 않는다.

### 0. 브리프
선생님께 묻거나 말씀에서 가져와 `00-brief.md` 를 쓴다. 모르는 칸은 비워 두고 묻는다.
- 영상 이름(폴더 이름, 한글 · 영문 · 숫자 · 하이픈)
- 범위: 소단원 파일 · 슬라이드 번호 (`docs/textbook/index.md` 에서 찾는다. 없으면 선생님께 교과서 변환을 먼저 부탁한다)
- 학습 목표 한 줄 · 대상(학년) · 목표 길이
- 내레이션을 쓰는지(기본: Supertonic F1) · 학생 참여 질문(생각할 시간)이 있는지

### 1. 수업 자료 정리 ✋
`content-editor` 를 부른다 → `01-content.md`. 선생님께 **고른 문장 · 뺀 것 · 확인이 필요한 곳**을 보여 주고 승인받는다.
`[확인 필요]` · 가정한 숫자 · 자료에 없는 것은 이때 모두 결정한다.

### 2. 레퍼런스
`art-director` 를 부른다 → `02-look.md`(쓸 부품 · 움직임 토큰 · **없는 것**). 없는 부품 · 값이 있으면 **3단계로 가기 전에** 선생님께 묻는다(만들지 않는다).

### 3. 장면표 ✋
`director` 를 부른다 → `03-scenes.md` + `narration.json`. 승인받을 때 보여 줄 것: 장면 순서 · 화면 글(쪽수) · 대본(읽기 표 적용) · 머무는 종류 · 필요한 그림 · 선생님께 물을 것.

### 4. 스냅보드 ✋
`builder` 를 부른다. **먼저 그림을 확인한다.**
- 필요한 그림이 `src/assets/photos/` 에 없으면 → `builder` 는 직접 그리지 않고 `out/<영상이름>/그림-필요-목록.md` 를 쓰고 **멈춘다.** 선생님이 agy나 코덱스로 그림을 만들어 `src/assets/photos/` 에 넣고 `SOURCES.md` 에 한 줄 적은 뒤 "넣었어"라고 하면 이어서 한다.
- 그림이 다 있으면 `scripts/sync-parts.sh <영상이름>` 으로 부품을 복사하고, 장면마다 대표 한 장면을 찍어 `snap/` 에 둔다. 선생님이 한 장씩 보고 승인한다.

### 5. 생성 · 검수
- `builder`: 내레이션(`scripts/make-voice.py`) → `durations.json` 으로 **장면 길이를 내레이션에 맞춤** → 효과음(`scripts/make-sfx.sh`) → 컴포지션 → `npm run check`.
- `critic`: 렌더 전 검수(문서 값 · 쪽수 · 부품 대조). 불통과는 `gates.md` 에 번호 목록으로. `builder` 가 그 목록만 고친다(3번까지, 그래도 남으면 선생님께 묻는다).
- 내레이션을 만든 뒤 **받아쓰기로 대본과 비교**해 읽기가 다른 곳을 보고한다(`docs/sound.md` 2장). 소리는 선생님이 직접 듣는다.

### 6. 렌더
`builder`: 렌더 → `loudnorm=I=-16:TP=-1.5:LRA=11` 로 소리 크기 맞추기. `critic`: `scripts/check-render.sh` 로 정지 · 무음 · 음량 · 밝기를 재서 **읽을 시간 · 생각할 시간 · 마지막 2초가 아닌 곳은 불통과**로 `gates.md` 에 적는다(`docs/check.md`). 판정이 통과여도 **선생님이 직접 시청**한다(소리 · 1배속).

### 7. 규칙 남기기
선생님이 영상을 보고 고친 것 · 새로 정한 것은 **같은 대화 안에서 해당 `docs/` 문서(design · motion · video · sound · check)에도 고쳐 적는다.** 적을 때마다 "이번 장면만 예외"인지 "다음에도 쓸 기본값"인지 한 줄로 적고 날짜와 출처("선생님 결정, 날짜")를 단다. 읽기가 틀린 낱말은 `docs/sound.md` 읽기 표에 더한다. 문서에 없던 부품 · 값을 영상에서 썼다면 먼저 선생님께 묻고, 승인받은 것만 문서에 올린다. — 1주차 motion.md 0-1

## 산출물 모양
`out/<영상이름>/` 안: `00-brief.md` · `01-content.md` · `02-look.md` · `03-scenes.md` · `narration.json` · `audio/` · `snap/` · `check/` · `gates.md` · `그림-필요-목록.md`(필요할 때) · HyperFrames 프로젝트 파일 · `renders/`

## 막혔을 때
| 상황 | 하는 일 |
|---|---|
| 자료에 없는 내용이 필요 | 쓰지 않고 선생님께 묻는다 |
| 문서에 없는 값 · 부품 | 짓지 않고 묻는다(기본값 후보 한 줄과 함께) |
| 그림이 필요 | `그림-필요-목록.md` 를 쓰고 멈춘다 |
| 읽기가 틀림 | 대본을 소리 나는 대로 고치고 읽기 표에 더하자고 제안 |
| critic 불통과가 3번 고쳐도 남음 | 멈추고 번호 목록과 함께 선생님께 묻는다 |

# 노션톡 사이클 · 수업 모션 하네스 시작 저장소

교과서 단원을 넣으면 **선생님이 고른 레퍼런스의 룩과 움직임으로** 수업 모션 영상을 만드는 하네스를 직접 짓는 저장소입니다.

이 저장소에는 **기본 룩이 없습니다.** 색 · 부품 · 움직임은 모두 선생님의 레퍼런스에서 만듭니다.
(신문 다큐멘터리 룩 예시는 `look-newspaper` 브랜치에 따로 있습니다. 참고용입니다.)

## 들어 있는 것

| 폴더 | 내용 |
|---|---|
| `docs/textbook/` | 교과서 md 형식(`_format.md`) · 목차(`index.md`) · 실습용 예시 원고(`sample-unit.md`) |
| `templates/look/` | 룩 빈 양식: `design.md`(값 없음) · `roles.md`(부품 역할 칸 7개) |
| `src/assets/fonts/` | 무료 한글 글꼴 (Pretendard · Noto Serif KR, 라이선스 포함) |
| `src/assets/photos/` | 사진 출처 표 (`SOURCES.md`) |
| `references/` | 레퍼런스 영상 · 이미지를 넣는 곳 (원본 파일은 저장소에 안 올라감) |

## 선생님이 만들 것

| 파일 | 만드는 때 |
|---|---|
| `docs/textbook/<소단원>.md` | 교과서 PDF를 넣을 때 |
| `docs/design.md` · `src/parts/` | 레퍼런스로 룩을 만들 때 |
| `docs/motion.md` | 레퍼런스 영상으로 움직임을 잴 때 |
| `docs/video.md` | 화면 규칙 질문 3개에 답할 때 |
| `CLAUDE.md` · `.claude/agents/` · `.claude/skills/make-video/` | 하네스를 지을 때 |
| `out/<영상이름>/` | 영상 한 편마다 (저장소에 안 올라감) |

## 시작 순서 (프롬프트)

한 번에 하나씩 보내세요.

1. **둘러보기:** `이 저장소를 둘러보고 폴더마다 무엇이 있는지, 내가 무엇을 만들어야 하는지 쉬운 말로 설명해줘. 아직 아무것도 만들지 마.`
2. **교과서:** (PDF 첨부) `교과서 PDF를 docs/textbook/_format.md 형식으로 소단원별 md로 바꿔줘. 본문 · 사료 · 표는 글자 하나 바꾸지 말고 문단마다 쪽수를 달아줘. 다 하면 index.md를 채우고 애매했던 곳을 알려줘.`
3. **룩:** (레퍼런스를 `references/<이름>/`에 넣고) `references/<이름>을 분석해서 templates/look/의 양식대로 docs/design.md와 src/parts/ 부품을 만들어줘. 값마다 레퍼런스 어디서 왔는지 적고, 레퍼런스의 사진 · 글자 · 로고는 가져오지 마. 부품은 견본 글로 한 장씩 찍어서 보여줘.`
4. **움직임:** `references/<이름>의 영상을 재서 docs/motion.md를 만들어줘. 먼저 움직임 성격 후보 3개를 주고 고르게 해줘. 장: 1 Primitives · 2 Semantic · 3 Pattern(부품별) · 4 머무는 시간 · 5 카메라. 값마다 몇 초에서 잰 값인지 적어줘.`
5. **화면 규칙:** `docs/video.md를 만들어줘. 교실 TV 기준이야. 배경 밝기 / 글자 크기 느낌 / 마지막 정리 화면, 세 가지만 기본값과 함께 물어봐.`
6. **하네스:** `수업 영상 하네스를 만들어줘. CLAUDE.md(목적 · 규칙 3개 · 폴더 · 고정/참조/금지 · 순서), .claude/agents 5명(content-editor · art-director · director · builder · critic), .claude/skills/make-video(브리프 → 교과서 정리 ✋ → 레퍼런스 → 장면표 ✋ → 스냅보드 ✋ → 생성 · 검수 → 렌더 → 규칙). 룩과 움직임은 docs와 references에서만 가져오고, 문서에 없는 값은 지어내지 말고 물어보게 해줘.`
7. **점검:** `하네스를 점검해줘. 문서끼리 다른 값이나 규칙이 있으면 찾아서 알려주고 고치지는 마.`

그다음부터는 `수업 영상 만들자` 한 줄로 시작합니다.

## 지킬 것
- 내용은 교과서 md에서만, 쪽수와 함께.
- 교과서 원문(`docs/textbook/` 변환본)과 영상 결과물(`out/`)은 공개 저장소에 올리지 않습니다.
- 레퍼런스에서는 느낌(색 계열 · 글자 성격 · 구도 · 카메라 · 전환 · 박자)을 가져오고, 프레임 · 사진 · 글자 · 음악 · 로고 같은 원본은 가져오지 않습니다.
- 레퍼런스가 있으면 레퍼런스가 우선입니다. 다른 영상이나 예시 룩을 기본값으로 쓰지 않습니다.
